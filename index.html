Features

⚡

Real-Time Messaging

Instant message delivery with Socket.io. No delays, just pure real-time communication.

💬

Multiple Rooms

Create and join different chat rooms. Organize conversations by topic or team.

👥

User Presence

See who's online in real-time. Track active users in each room instantly.

🔒

Secure Authentication

Built with Supabase authentication. Your data is protected and secure.

🎨

Beautiful UI

Clean terminal interface built with blessed. Intuitive and easy to use.

👑

Admin Controls

Powerful moderation tools. Ban, kick, and manage rooms with ease.

Installation

1

Install via npm

npm install -g @bnjkhr/cli-chat-client
2

Run the application

cli-chat
3

Create an account

Register with your email, confirm it, and start chatting!

Available Commands

/help

Show all available commands

/join #room

Join a chat room

/rooms

List all available rooms

/users

List users in current room

/msg @user text

Send a private message

/quit

Exit the application
